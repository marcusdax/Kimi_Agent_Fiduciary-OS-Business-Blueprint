# 06 — Machined Chrome: console design language

**Status:** shipped in `src/ui/console.css` · **Applies to:** the provenance console and any
future trust-core surface · **Aligned with:** the machined-metal token system in
`fiduciary-os/frontend/src/styles.css` (`--chrome-edge`, `--card-fill`, `--card-sheen`,
`--card-brush`, `--card-bevel`).

---

## 1. The flow it serves

The console exists to walk one loop, in order, every time:

```
CONNECT ──► COMPUTE ──► INSPECT ──► VERIFY
 scoped     a number     its receipt   the chain
 token      is cut       is stamped    recomputes
```

The layout is that sentence. The masthead carries identity and the connection
readout; the connect card is the airlock; the grid below it is the instrument
bay — tax engine, market context, evidence ledger, source registry — and the
footer restates the disclosure. Nothing on the screen is outside the loop.

Design consequence: **modules are numbered, not decorated.** Each card is
etched with an index (`01 · FEDERAL INCOME TAX`) generated by CSS counters, so
the reading order is visible without a single extra DOM node.

## 2. Material system

The metaphor is an instrument panel milled from gunmetal and anodized
aluminium. It is built from four repeatable parts:

| Part | Construction | Meaning |
|---|---|---|
| **Plate** | `plate-fill` gradient + `plate-brush` (1px brushed lines) + `plate-sheen` + bevel pair | a card; machined stock |
| **Hairline** | 1px `chrome-edge` gradient masked to the border band (`mask-composite: exclude`) so it follows the corner radius | a real edge; it brightens on hover |
| **Well** | recessed `linear-gradient(180deg, #0b0f16, #10151e)` + inset top shade | anywhere a number is displayed or typed |
| **Readout** | inset pill with bezel + status LED dot | system state, freshness state |

Chrome is **structure, not decoration**: specular gradients only ever trace a
real boundary (card rim, bezel, masthead rule, footer rule) or an affordance
(primary button). Nothing glows that is not an edge or a control.

## 3. Colour

- **Accent:** anodized cyan (`#5fd8e8`) — interactive affordances only. A second
  accent would compete with the freshness palette, which owns meaning.
- **Freshness (semantic, untouched):** green `#4ecb71` current · amber `#e2b04c`
  aging · red `#ff8089` stale · magenta `#d795f2` placeholder. Every badge also
  carries a word; colour is never the only signal.
- **Ground:** deep-space `#05070b` with a blueprint grid floor (56px major /
  14px minor cells, radially masked so it fades before it competes) and one
  static specular band across the viewport — light, not motion.

## 4. Typography

- **Legends** (field labels, figure keys, card titles, chips): uppercase,
  letterspaced monospace — etched panel legends.
- **Readings:** UI sans, tabular figures everywhere a number appears, so columns
  align and digits do not shimmer when a value updates. Large figures use a
  vertical metallic gradient clipped to the glyphs; body text stays solid for
  contrast (AA throughout).
- **Wordmark:** `FIDUCIARY OS` set in a 178° chrome gradient with a hard mid-stop —
  the classic machined-specular band — tracked out, uppercase.

## 5. Motion policy

- State transitions: 120–160ms ease, colour/border only, plus a 1px press
  translation on buttons.
- Exactly one ambient motion: a slow sheen drift (9s) along the masthead's
  machined rule — the console's "powered on" indicator.
- `prefers-reduced-motion: reduce` kills all of it, including the sheen.

## 6. Non-negotiables inherited from the trust product

1. No `innerHTML` with server data (audit rule `dom-html-injection`).
2. Strict CSP: no inline script or style; this file is the whole skin.
3. Focus is always visible: 2px cyan outline, offset 2px.
4. Contrast above WCAG AA (body >12:1, muted >5:1).
5. The disclosure is rendered, always, via `DISCLOSURE` in `format.js`.

## 7. Extending the language

- New module → new `.card`; the index etches itself.
- New value → put it in a `.figure` well with a `.k` legend and a `.v` reading,
  and attach a `.receipt` — a value with no receipt is a design bug, not a
  missing feature.
- New state → use the freshness palette; do not invent a sixth colour.
- If a surface does not show a number, a receipt, or a control, question
  whether it belongs on this screen.
